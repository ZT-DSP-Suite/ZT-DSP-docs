# Contributing to ZT-DSP-docs

This repository holds the ZT-DSP protocol specification. It is prose, not code.

## What licence a contribution carries

The specification is published under CC BY-SA 4.0, and that is the only licence
that applies to this repository. No Contributor License Agreement is used here,
and no right to relicense is asked for.

CC BY-SA 4.0 grants no right to relicense a contribution under different terms.
A clause asking for that right would be a promise this repository cannot keep, so
the clause is not here.

Commercial licensing covers the code. It does not reach this text. See
[LICENSING.md](LICENSING.md).

## How a contribution is recorded

1. Sign off every commit:

```
git commit -s
```

2. Add one line to [CONTRIBUTORS.md](CONTRIBUTORS.md), so the authorship record
   survives the pull request being deleted.

The `Signed-off-by` line in each commit is the record that you have the right to
submit the work under CC BY-SA 4.0. Nothing else is required.

## When we review and merge

Review and merge usually happen between Friday and Sunday, UTC+8. The window is a
habit of two maintainers with other work, not a service commitment. A pull request
that waits over a weekday is waiting for a person, not rejected.

## What we will not merge

- Any file whose copyright header or `SPDX-License-Identifier` line has been removed or altered.
- Text copied from a project whose licence is incompatible with CC BY-SA 4.0.
- Contributions you do not have the right to licence.
